Scope#

The requirements below describe the requirements for an IPC mechanism to be used to allow communication between the library and the daemon.

Functional requirements#

Resilience to connection loss
status: valid
security: NO
safety: ASIL_B
reqtype: Functional
version: 1
derived from: feat_req__sec_crypt__access_control, feat_req__sec_crypt__no_key_exposure, feat_req__sec_crypt__os_protection

The IPC shall be resilient to crash or connection loss. If one of the participating processes dies or the connection is lost in any other means the users of the IPC shall be notified appropriately. The client shall not block indefinitely or silently operate on a dead connection.
comp_req__ipc__resilience_to_connection_loss
